# Classes and Objects

- Class
  - Template or blueprint for creating objects. Bundles data and functionality together
    - Data
      - Stored as attributes
        - Variables
    - Functionality
      - Defined as functions

- Attributes
  - Class level or instance level data stored on the object

- Constructor
  - A method that is automatically called when a new object (instance) of a class is created
  - Sets the inital state of an object by assigning values to the instance values
  - The `self` parameter is the first argument and referes to the instance being constructed
  - Python constructors use the`__init__` method
  - Every time you call a class, `__init__` is called behind the scneds


- Object
  - A live instance with its own unique state and behavior

- Self
  - Self represents the current method that is calling the object
