# Loops

## For Loops

- `for` loops iterate over any sequence of items processing them in order. Executes a task for each item
  - lists
  - strings
  - ranges
- 0 based index
  - `for <variable_name> in <list>:`
    - `logic applied to each item`

## While Loops

- `while` loops keep executing as long as a condition is true. Good when the number of iterations is unknown
- Always make sure the condition will become false at some point, otherwise you will have a infinite loop

## When to use for and while loops

- `for` loops
  - When the number of iterations is known
  - Cleaner syntax for collections
  - iterates over sequences
    - lists
    - ranges
    - strings

- `while` loop
  - When the number of iterations is unknown
  - Runs as long as a condition is true
  - More flexible, but has risk of infinite loop
