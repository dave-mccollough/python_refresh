# Python Operators

- Operators are a symbol or keyword that performs operations on values or variables
  - Also known as **operands**

## Arithmetic Operators

- Addition
  - `5 + 2` = 7
- Subtraction
  - `5 - 2` = 3
- Multiplication
  - `5 * 2` = 10
- Division
  - `6 / 3` = 2.0
- Exponent
  - `2 ** 3` = 8
- Modulo
  - `17 % 5` = 2

## Assignment Operators

- Basic assigment
  - `=`
    - `x = 10`
- Add and assign
  - `+=`
    - `y += 5`
    - This is the same as `y = y + 5`
- Multiply and assign
  - `*=`
    - `z *= 2`
    - This is the same as `z = z * 2`

## Comparison Operators

- Returns a boolean value
- Greater Than and Less Than
  - `>` and `<`
    - `8 > 5` True
    - `5 < 8` True
  - Equal and Not Equal
    - `==` and `!=`
      - `5 == 5` True
      - `11 != 10` True
  - Greater than or equal or Less than or equal
    - `>=` and `<=`
      - `10 >= 6` True
      - `3 <= 6` True

## Logical Operators

- Combine multiple conditions for programmatic decision making
- `and`
  - Both conditions must be true
    - `(5 > 3) and (10 < 11)` True
- `or`
  - At least one condition must be true
    - `(5 < 3) or (10 < 11)` True
